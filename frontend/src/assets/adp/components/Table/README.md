# Table

Headers in title weight, body rows in body, a hairline between rows.

- Headers are the title style on the surface; rows are body with a borderSubtle rule.
- A row highlights with the accent fill on hover; selection adds no second colour.
- Numbers align right; text aligns to the reading direction.

## Classes

- `adp-standard-table`

The classes are plain CSS from `components/bundle.css`; behaviour (focus management, keyboard handling) comes from the consuming framework's accessible primitives.
