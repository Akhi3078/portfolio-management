# Card

A surface with the card shadow, space-4 padding and a title in h3.

- Cards group one thing: a record, a setting, a summary. Lists of cards sit in a grid at space-5.
- A card is defined by its surface and shadow, with a borderSubtle hairline; it never gets a heavier border.
- Nest nothing with its own shadow inside a card.

## Classes

- `adp-standard-card`
- `adp-standard-card-title`
- `adp-standard-card-body`

The classes are plain CSS from `components/bundle.css`; behaviour (focus management, keyboard handling) comes from the consuming framework's accessible primitives.
