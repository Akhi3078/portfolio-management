# Badge

A status chip in one of the four semantic colours, text in label.

- Badges state a status, not an action: Delivered, Pending, Overdue, Note.
- Success, warning, danger and info are the only variants, so a colour always means the same thing.
- The words carry the meaning; colour alone is never the only signal.

## Classes

- `adp-standard-badge`
- `adp-standard-badge-success`
- `adp-standard-badge-warning`
- `adp-standard-badge-danger`
- `adp-standard-badge-info`

The classes are plain CSS from `components/bundle.css`; behaviour (focus management, keyboard handling) comes from the consuming framework's accessible primitives.
